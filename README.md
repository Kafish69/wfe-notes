# wfe.notes

Interactive notes + practice for **Web Development Fundamentals** (HTML & CSS, weeks 1–6).

**Live:** https://kafish69.github.io/wfe-notes/

8 chapters: links/tables/images · semantic HTML · CSS basics & cascading · selectors & specificity · box model & display · layout & flexbox · forms & accessibility · HTTP request/response.

Every chapter has live demos (link path trainer, `<picture>` fallback, live selector tester, specificity calculator, box model sliders, collapsing margins, flexbox playground, flex-grow calculator, form → HTTP request, status-code game) and a quiz. Exam practice: 20 random questions from 135, with a per-chapter breakdown.

Not official. The course slides are leading.
