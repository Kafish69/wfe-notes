# wfe.lab

Notes + practice for **Web Development Fundamentals** (HTML & CSS, weeks 1–6), in **English and Roman Urdu**.

**Live:** https://kafish69.github.io/wfe-notes/

- **Notes**: 9 chapters in easy words (English or Roman Urdu) with live demos: link path trainer, `<picture>` fallback, live selector tester, specificity calculator, "who wins?" puzzles, rgb↔hex mixer, rem vs em, box model sliders, collapsing margins, flexbox playground, flex-grow calculator, form → HTTP request, status-code game, and a quiz per chapter
- **Mock exam**: 20 random questions from every chapter (multiple choice + type the answer), easy / medium / hard, 30-min timer, score per chapter and full review
- **Code**: write the selector, declaration or tag, instant check
- **Fill & predict**: calculate widths, weights, colours, paths, HTTP answers
- **Quiz**, **Flashcards** (81), **Cheat sheet**

264 questions in total. Answers are checked flexibly (spaces, quotes, attribute order, units).

Not official. The course slides are leading.
